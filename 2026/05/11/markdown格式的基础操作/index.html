一、标题

二、段落与换行

段落：空一行分隔
换行：在行尾加两个空格，或使用 <br>

三、文字样式

效果 语法 示例
粗体 **文字** 或 __文字__ *粗体*
斜体 *文字* 或 _文字_ *斜体*
粗斜体 ***文字*** **粗斜体**
删除线 ~~文字~~ ~~删除线~~
行内代码 `代码` `code`

四、列表

无序列表

用 -、+ 或 * 开头：

  • 苹果
  • 香蕉
    • 小香蕉（缩进2空格或Tab）
  • 橙子

有序列表

  1. 第一步
  2. 第二步
  3. 第三步
    1. 子步骤
    2. 子步骤

六、代码块

行内代码
用一对反引号包裹：

使用 npm install 安装依赖

代码块
用三个反引号包裹，可指定语言实现高亮：

```python
def hello():
print(“Hello, World!”)
```

```bash
echo “Hello”
```

七、链接与图片

链接

八、分隔线

用三个或以上的 -、* 或 _：

---

***

___

九、表格

用 | 分隔列，用 — 分隔表头，可指定对齐：

左对齐 居中对齐 右对齐
内容1 内容2 内容3
内容4 内容5 内容6

十、任务列表（复选框）

  • 已完成的事项
  • 未完成的事项
  • 待办事项

十一、转义字符

如果需要在文本中显示 Markdown 特殊符号，用反斜杠 \ 转义：

* 这不是斜体 *
` 这不是代码 `
# 这不是标题
