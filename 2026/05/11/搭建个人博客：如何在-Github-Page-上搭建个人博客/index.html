搭建个人博客：如何在 GitHub Pages 上搭建个人博客

想要一个属于自己的技术博客，记录学习、分享心得，但又不想折腾服务器和域名？GitHub Pages 绝对是你的最佳选择。它免费、稳定，并且与 Git 工作流无缝集成，非常适合开发者。 本文将手把手教你，如何从零开始，在 GitHub Pages 上快速搭建一个简约、高效且完全由你掌控的个人静态博客。

一、核心原理与工具选择

GitHub Pages 是 GitHub 提供的一项静态站点托管服务。它直接从你的 GitHub 仓库获取 HTML、CSS、JavaScript 文件，运行并通过一个 username.github.io 的域名发布网站。 对于博客系统，我们不会手动编写每个页面的 HTML。社区已经有了非常成熟的静态站点生成器来帮我们完成这项工作。其工作流程如下：

Markdown 文章 → Hexo 生成 → 静态文件 → git push → GitHub → 自动发布 → 🌐 线上博客

在众多生成器中，Hexo 和 Jekyll 是最流行、对 GitHub Pages 支持最友好的两个。我们做个简单对比：
表格 特性 Jekyll Hexo 官方支持 ✅ GitHub Pages 内置支持 ❌ 需本地构建后推送 运行环境 Ruby Node.js 生成速度 一般 极快 主题生态 丰富 海量精美主题 上手难度 中等 对新手更友好 本文将以 Hexo 为例进行演示。

二、环境准备

在开始之前，请确保你的电脑上已经安装了以下工具

1. Node.js（包含 npm） Hexo 的运行环境。

前往 Node.js 官网 下载长期支持版并安装 安装后，打开终端（或命令提示符），运行以下命令检查：
node -v npm -v

2. Git 版本控制和推送代码的工具。

前往 Git 官网 下载并安装 安装后，在终端运行：
git --version

3. GitHub 账户

如果你还没有，请前往 GitHub 注册一个。

三、安装 Hexo 并初始化博客

环境准备好后，我们就可以开始安装 Hexo 了。

1. 安装 Hexo 命令行工具

打开终端，执行以下命令全局安装 Hexo：
npm install -g hexo-cli

安装完成后，可以通过以下命令检查：
hexo version

2. 初始化博客项目

选择一个你喜欢的目录（比如 D:\Projects 或 ~/Documents），在终端中进入该目录，然后执行：
hexo init my-blog
my-blog 是你的博客文件夹名称，可以自定义 cd my-blog 这个命令会创建一个名为 my-blog 的文件夹，并在里面生成博客所需的所有基础文件。

3. 安装依赖

进入博客文件夹后，安装必要的依赖包：
npm install

四、本地运行与体验

现在，你的第一个博客已经搭建好了！让我们在本地看看它长什么样。

1. 启动本地服务器

在博客目录下执行：
hexo server
或简写为 hexo s 你会看到类似下面的输出：
INFO Start processing INFO Hexo is running at http://localhost:4000 . Press Ctrl+C to stop.

2. 预览博客

打开浏览器，访问 http://localhost:4000，你就能看到默认的 Hexo 博客页面了！

3. 创建第一篇文章

在终端中（新开一个或按 Ctrl+C 停止服务器后），执行：
hexo new
“我的第一篇文章” 这会在 source/_posts 目录下创建一个名为 我的第一篇文章.md 的文件。用你喜欢的文本编辑器（如 VS Code）打开这个文件，你会看到类似下面的内容
---
title:
我的第一篇文章
date: 2024-01-01 00:00:00
tags: ---
这里开始写你的文章内容…
在 --- 下面添加一些内容，比如： 全屏 下载 适应 代码 预览
列表项 1 列表项 2 列表项 3
三级标题 二级标题

保存文件后，重新运行 hexo server，刷新浏览器页面，你就能看到新文章了！

五、部署到 GitHub Pages

本地运行成功后，我们把它部署到 GitHub Pages，让全世界都能访问。

1. 创建 GitHub 仓库

登录 GitHub，点击右上角的 “+” 号，选择 “New repository”。
仓库名称必须严格按照此格式： plain 复制 你的用户名.github.io
例如，如果你的 GitHub 用户名是 zhangsan，那么仓库名就是 zhangsan.github.io。

其他设置保持默认即可，点击 “Create repository”。

2. 配置部署信息

回到你的博客目录，安装 Hexo 的部署插件：
npm install hexo-deployer-git --save

然后打开博客根目录下的 _config.yml 文件（这是 Hexo 的主配置文件），找到最后的 deploy 部分，修改为： yaml

3. 生成静态文件并部署

在终端中依次执行以下命令：

生成静态网站文件
hexo generate
或简写为 hexo g

部署到 GitHub hexo deploy
或简写为 hexo d

第一次部署时，可能会提示你输入 GitHub 的用户名和密码（如果使用 HTTPS 方式）。
注意：密码处需要输入 Personal Access Token，不是 GitHub 登录密码。

4. 访问你的在线博客

部署完成后，等待大约 1-2 分钟，
然后在浏览器中访问： [https://你的用户名.github.io] (https://你的用户名.github.io)

恭喜！你的个人博客已经成功上线了！

七、后续维护流程

以后每次写新文章，只需要：
hexo new "文章标题" 创建新文章
source/_posts/文章标题.md 撰写内容
hexo clean
hexo g 生成静态文件
hexo s 本地预览（可选）
hexo d 部署到 GitHub

常见问题

1. 部署失败怎么办？

检查 _config.yml 中的 repo 地址是否正确 确认 GitHub 仓库名格式是否正确 尝试使用 SSH 方式部署（需要配置 SSH key）

2. 访问 GitHub Pages 显示 404？

首次部署后需要等待 1-2 分钟 确认仓库的 Settings -> Pages 中 Source 是否正确设置为 main 分支

3. 如何绑定自定义域名？

在域名注册商处添加 CNAME 记录，指向 你的用户名.github.io 在博客 source 目录下创建 CNAME 文件，里面写上你的域名 在 GitHub 仓库的 Pages 设置中也可以配置自定义域名
